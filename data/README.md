# Pokédex data

`dex.js` is generated by `scripts/build_dex.py` from the pinned PokéAPI CSV revision. It contains species, Pokémon forms, stats, types, abilities, moves, items, evolution conditions, game groups, and learnsets. Do not edit it by hand. See `docs/SOURCES.md` for the source revision, rebuild steps, and coverage limits.

`mega.js` is the curated mapping between Mega and Primal forms, their normal forms, and the required stones or orbs. It uses stable IDs from `dex.js`. After changing the mapping or refreshing the data, run `python scripts/check_dex.py` and `node scripts/check_team_stats.js`.
