# Pokémon Type Effectiveness Guide

A clean, casual, offline-friendly **Pokémon type resistance and effectiveness calculator** covering **all types from Generation 1 to Generation 9**.

Designed for quick reference, clarity, and ease of use — no clutter, no accounts, no frameworks.

---

## ✨ Features

- ✅ **All 18 Pokémon types** (Gen 1–9)
- 🔁 **Single or dual-type selection, all Type-effectiveness altering abilities, and Terastallize**
- ⚔️ **Attack mode**
  - Shows how effective your selected type(s) are *when attacking*
- 🛡️ **Defense mode**
  - Shows resistances, weaknesses, and immunities *when defending*
- 📊 Automatically calculates:
  - 4× (double super-effective)
  - 2× (super-effective)
  - 1× (neutral)
  - ½× (resisted)
  - ¼× (double resisted)
  - 0× (immune)
- 🌙 **True black Dark Mode** + Light Mode
- 📴 **Fully offline** — pure HTML, CSS, and JavaScript
- 📱 Responsive and aspect-ratio safe

---

## 🧠 How It Works

- Uses the official Pokémon type effectiveness chart
- Multiplier stacking is handled mathematically for dual types
- Attack and Defense modes invert calculations correctly
- All calculations are done client-side

No libraries. No APIs. No dependencies.

---

## 🎯 Intended Use

- Casual reference during gameplay
- Team planning
- Learning type matchups
- Quick checks without opening external sites

This tool is intentionally lightweight and not a competitive optimizer.

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (custom properties + transitions)
- Vanilla JavaScript
